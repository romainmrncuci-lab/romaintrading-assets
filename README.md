# Romain Trading · visuels

Visuels hebdomadaires « Récap macro » publiés dans le Discord RomaiNxTRADES.

- `recap/` : un visuel par semaine (`recap-AAAA-MM-JJ.png`) et le dernier en date (`latest.png`).
- `tools/` : génération du visuel (`recap_data.js` calcule les données, `render_recap.py` dessine l'image).

Contenu éducatif, ne constitue pas un conseil en investissement.
